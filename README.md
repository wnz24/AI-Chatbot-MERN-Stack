# AI Chatbot - MERN Stack with TypeScript

This project is an AI-powered chatbot built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) with **TypeScript**. It uses **OpenAI's GPT model** for natural language understanding and response generation, allowing users to interact with a chatbot in real-time. This project demonstrates how to create a full-stack application with real-time messaging and AI-powered responses.

## Features

- **Real-time Messaging**: Users can send messages and receive responses instantly.
- **AI-Powered Responses**: The chatbot uses OpenAI’s GPT model to generate intelligent responses.
- **Modern UI**: The frontend is designed using React and styled with TailwindCSS for a modern, responsive experience.
- **User Authentication**: Users can sign up, log in, and manage their sessions.
- **TypeScript**: The entire application is written in TypeScript to ensure type safety and improved developer experience.

## Technologies Used

### Frontend:
- **React.js** (with TypeScript)
- **TailwindCSS** for styling
- **Socket.io** for real-time communication
- **Zustand** for state management
- **DaisyUI** for UI components

### Backend:
- **Node.js**
- **Express.js**
- **MongoDB** for data storage
- **OpenAI API** for AI-powered responses
- **Socket.io** for real-time communication

### Development Tools:
- **TypeScript** for type safety
- **ESLint** and **Prettier** for code quality
- **GitHub Actions** for CI/CD

3. **MongoDB** (either locally or through MongoDB Atlas)
